# SubsetJuliaVM iOS App - User Manual

SubsetJuliaVM is an iOS app that lets you write and run Julia code directly on your iPad or iPhone. No internet connection required - all code runs locally on your device.

## Quick Start

1. **Launch the app** - You'll see the Editor view with sample code
2. **Tap Run** - Execute the code and see output in the log panel
3. **Try REPL** - Switch to REPL tab for interactive coding
4. **Explore Samples** - Browse 50+ example programs by category

## Supported Julia Features

- Variables, arithmetic, comparisons
- Control flow: `if/else`, `for`, `while`, `break`, `continue`
- Functions: user-defined, recursive, multiple dispatch
- Arrays: 1D/2D, comprehensions, broadcasting
- Higher-order: `map`, `filter`, `reduce`, lambdas
- Structs: mutable and immutable
- Error handling: `try/catch/finally`
- Macros: `@time`, `@assert`, `@show`
- Complex numbers, Unicode identifiers

## Requirements

- iOS 17.0 or later
- iPad or iPhone
